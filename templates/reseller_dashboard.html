API Endpoint & Action Guide
GET / POST {{ base_url }}/api/v1/manage
GET / POST {{ base_url }}/api/v1/manage?key=<action>&...

Parameters:
- key: Your API Key (e.g. {{ user.api_key }})
- action: 'add', 'add_license', 'reset_hwid', 'update', 'status', 'remove'
- username / uid: App username (1-char to unlimited letters)
- password: App password (1-char to unlimited letters)
- license_key: (Optional) Custom license string or auto-generated
- duration: Number of days (1-365, required for 'add' or 'update')
